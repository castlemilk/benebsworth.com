## Follow one root continuously

The horizontal plane represents the complex input. Height represents the real part of a square root. The amber marker follows one root continuously while its blue projection traces the input circle below.

## Try these experiments

1. Choose **One circuit**. Scrub from start to finish: the input returns, but the root changes from +1 to −1.
2. Choose **Two circuits**. After the full sweep, both input and selected root return to their starting values.
3. Choose **Near the branch point**. The roots are closer together, but one circuit still exchanges them. Only the winding count determines this exchange for these circular paths.

At radius 1 and one-quarter of a single input circuit, the tracked root is $(1+i)/\sqrt2$. Squaring it gives $i$, the correct input. The invariant is $w^2=z$ throughout the path.

## Read the projection carefully

The relation contains four real coordinates: two for the input and two for the root. This view drops the imaginary part of the root. Apparent intersections above the negative real axis do not join the two mathematical roots. The colours distinguish successive angular sheets in the projected picture.
