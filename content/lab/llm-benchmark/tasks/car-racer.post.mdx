### Reading the score

Real keyboard input drives the browser checks. Acceleration and steering must change the canvas and the requested vehicle telemetry; braking must reduce speed; restart must reset speed, heading and distance. These checks account for 70% of the score, with 30% from structural HTML checks.

The telemetry is supplied by the artifact itself, so it is not independent proof of physics correctness. Collision behavior, rival AI, checkpoint ordering, touch controls and visual quality still need manual inspection. The score should be read as a tested interaction subset, not a complete game review.
