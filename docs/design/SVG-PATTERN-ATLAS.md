The next collection adds 36 distinct constructions and original illustrations to the 28 reviewed SVG studies. Existing scientific diagrams, canonical logos, PNG masters and the three engraved originals stay unchanged. Mathematical patterns state their models; bespoke illustrations state their authored visual intent without claiming physical simulation or historical reconstruction.

## Common contracts

- Reuse the study registry, pure geometry and shared portable SVG renderer. No extra charting stack, raster wrappers or WebGL dependency.
- Use the existing fine stroke tier for permanent detail. Guides remain optional construction, never essential pattern geometry.
- Keep coherent graphite/vermilion ink and the existing appearance lab. Parameter controls change meaningful model properties; appearance controls never move coordinates.
- Preserve the 320×240 canvas with safe stroke margins and uniform scaling for mathematical shapes. Declare any projection honestly.
- Keep default SVG payloads and point counts bounded. Prefer fewer than 10,000 points per study, with an explicit ceiling of 25,000; curves never need an unbounded recursion or sampling loop.
- Treat intersections, tangencies and disconnected branches explicitly. A planar crossing does not imply a woven over/under relationship.
- Test every parameter corner, model-specific invariants, search metadata, deterministic recipe round-trips, transparency, coordinate/style separation and preserved baseline SVG hashes.
- Inspect real SVG renders at default and extreme parameters on paper/night surfaces, in monochrome and with construction hidden. Browser behavior and native download/print acceptance are separate checks.

## First-batch details

The octagonal textile clips complete source lines against eight half-planes. Standing-wave lace samples analytic per-cell level curves with cosine clustering at vertical tangencies, avoiding a general contour solver and ambiguous saddle cells. The Truchet construction shares exact tile endpoints; the Hilbert path is a finite recursive approximation. Closed rolling-circle patterns use the correct period for their integer ratio. Modular chord envelopes remain discrete constructions, not exact cardioids.

The reviewed baseline fixture records default SVG SHA-256 hashes from the 28-study source at PR145 head f8bcedbb. New registration must not silently change those existing SVG bytes. Deliberate future changes require their own explicit review rather than regenerating the fixture to make tests green.

## Second-batch details

The second batch adds an external rolling-circle crown, paired-thread triangular textile, two-state hexagonal Truchet patch, finite dragon-fold path, twin-source scalar contours and nested coprime star cycles. The crown defaults to its richer 5:2 radius ratio with 140% pen reach. No existing model, original asset or canonical logo is replaced.

Twin-source contours use canonical grid-edge identity and a bilinear asymptotic decider. Straight cell chords approximate the sampled bilinear contours, not exact analytic topology. Tests distinguish exact-level hits from saddle ties; neither occurs in the supported nine presets or the two finer reference cases. Model-only refinement is not a physical wave simulation.

Independent source/specimen review covered every one of the 63 supported model configurations at maximum monochrome weight/emphasis, plus light/dark defaults and model extrema, minimum-stroke defaults and guides-on stress views. SVG drawings are not browser screenshots. Exact-source browser/build checks and release approval remain separate gates.


## Third-batch details

Lissajous silk uses three phase-neighbor trajectories with curated phases 16°–56° in 10° steps, default 46°. Analytic equivalence checks exclude complete retracing, coincident neighbors and duplicate full-triplet settings while retaining real self-crossings. The sinusoidal textile is an area-preserving shear, not an angle- or length-preserving deformation. Rhombille parquet deduplicates exact lattice edges; its inset maximum is 70% because 80% collides at maximum line weight. The finite Lévy path retains actual contacts and overlaps.

The confocal loom samples separate ellipse and hyperbola coordinate families with one uniform scale; orthogonality belongs to the exact curves, not their straight sampled chords. Four parabolic string fans draw straight segments whose continuous envelopes are parabolas. Overlapping endpoint strings are replaced by their exact boundary union, and the central diamond is a guaranteed empty subset, not a claimed exact opening boundary.

Independent review accepted all 57 supported configurations at maximum monochrome weight/emphasis and default/minimum/maximum/thin/guides boards in both themes. Browser and export integration remain separate checks. Native range tests round the expected decimal step to avoid binary-addition noise, without relaxing numeric model validation.

The enlarged catalogue exposed DOM-test timeouts from keeping every thumbnail's vector primitives inline. Catalogue thumbnails now display the identical self-contained SVG bytes as eager images, while the selected workbench stays inline. No geometry is rasterized or changed. Artwork-only surfaces retain paired ink/background colors in forced-colors and print modes; controls, labels and focus remain system-controlled. Browser tests cover thumbnail loading, keyboard selection, forced-color states and print PDFs, with PDF visual review separate from computed-style assertions.
