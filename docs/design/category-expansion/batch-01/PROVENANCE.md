# Generation provenance

The ten subject concepts were generated for Ben Ebsworth on 17 November 2026 through the built-in `image_gen.imagegen` tool. Each concept had its own call and PNG output. The common request specified an engraved graphite and warm-ivory specimen with a restrained red detail, transparent background, clear margins and no text. Exact submitted requests are retained in `prompts/requests.json`.

The tool exposed `prompt` and `transparent_background`; both are recorded exactly. A square composition was requested in text. Model identifier, seed, quality setting and a numeric size parameter were not exposed and are not invented. Actual dimensions are measured from the PNG bytes in `manifest.json` and `review/alpha-metrics.json`.

ART04's recovered atom and AI-brain originals were visually inspected as family context. They were not supplied as image-generation inputs, copied into these new images, replaced or redistributed in this batch. Their historical prompts and companion SVGs remain unrecovered. The ten initial category requests used no referenced image input. Neuroscience revision 2 used this batch's own `10-neuroscience-r1.png` as its sole edit reference; the complete request and reference path are in `prompts/revisions.json`.

Every generated PNG was copied byte for byte to its versioned filename. No original was re-encoded, cropped, recoloured, flattened, vectorized or alpha-thresholded. The independent review composites use Pillow to display existing originals on labelled light/dark surfaces, at exact review sizes and in sampled edge crops. Those composites are secondary review artifacts, not new artwork concepts or scientific evidence.

No third-party stock artwork, vendor logo, external font file or editable vector master is included in this batch. No stock licence or open-source image licence is assigned by this record. The source provenance is the authorised generation request and its unchanged output, with exact upload hashes retained in `generation-receipts.json`.

The manifest distinguishes four existing topic keys from six proposed study labels. No image establishes scientific coverage, an article, taxonomy adoption, a biological model or knowledge-graph data. The `USAGE.md` table preserves each subject's interpretation limits.
