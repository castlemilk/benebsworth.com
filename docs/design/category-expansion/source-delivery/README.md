# Category artwork source delivery

This branch preserves the original review packets for all five category-art batches. It does not replace the 256px runtime artwork, change taxonomy, import a new component, or deploy a gallery.

## Scope and provenance

Batches 01, 02, 03 and 05 retain the exact source files from their completed Library archives. Batch 04 is deliberately stored under `batch-04/recovered/`: 17 recovered PNGs, ten prepared prompts, four actual generation receipts and the original early checkpoint. Later actual prompts/settings, the rejected opaque Information Theory revision and the final cumulative source patch remain missing. Prepared prompts are not evidence of later calls.

The source packets' original local-only/publication-blocked statements are dated historical receipts, not current branch status. No script in a recovered packet was executed merely because the packet contained it. This delivery independently decodes every PNG and matches all 50 selected originals to the previously verified Page receipt hashes. `selected-originals.json` connects each selected subject to its exact delivered bytes; `FILE-SHA256SUMS` covers this delivery's files.

The publication hold was reassessed on 17 November 2026: a read-only GitHub variable check returned `VERCEL_PREVIEW_CI_ENABLED=false`, matching the existing workflow's opt-in guard. No setting or credential changed. This branch is for review only; a draft PR is not visual acceptance, merge, production adoption or permission to enable a preview.

All art is illustrative metaphor, not scientific evidence. Proposed topic names do not establish existing article coverage. Existing canonical SVG symbols, original ART04 recovery and runtime category mappings remain untouched. Alpha residue, small-size legibility and other original review limitations remain applicable.

## Publication boundary

The GitHub review branch publishes these source artifacts to the repository audience. Files beneath `public/` would also become site-downloadable on eventual merge and production release, even without runtime imports. This task pushes a draft branch only; merge and deployment are held for separate review and privacy confirmation.
