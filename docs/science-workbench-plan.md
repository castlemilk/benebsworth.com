# Ten spatial science essays

Create three mathematics essays (singular values, spherical parallel transport,
complex square roots), three physics essays (polarisation, group velocity,
gyroscopic precession), and four electrical engineering essays (phased arrays,
three-phase rotating fields, waveguide cutoff, coaxial power flow).

Each essay uses the repository's editorial MDX palette, has a worked example,
sources, explicit model limitations, takeaways, and an embedded spatial lab.
Every lab also has its own discoverable route and a short experiment guide.

Pure numerical models supply geometry and readouts to a shared, lazy-loaded
Three.js workbench. Controls include phase scrubbing, play/pause, presets,
parameter sliders, camera views and reset. Reduced motion starts paused.
Off-screen and background work stops; WebGL failure retains a projected SVG
view with usable controls and quantitative feedback. Responsive layout and
theme-aware prose wrap a deliberately dark scientific instrument stage.

Validation covers mathematical invariants, content/registry integration,
production export including markdown siblings and OG assets, and Playwright
checks of every new blog/lab, pixels, controls, mobile, theme, reduced motion,
and WebGL fallback. Existing work in the checkout is preserved.
