The moves that usually mean downtime, made safe by construction.

Shadow tables

Every change builds in a shadow copy of the table first. The live table keeps serving reads and writes the whole time; the cutover swaps them in milliseconds.

0042_add_user_rank.sql shadow build 0%

Lock-free backfill

Backfills run in bounded batches and yield whenever replication lag moves. Your p99 does not notice.

Type rewriting

int to bigint, text to jsonb, across millions of rows. Rewritten in place and verified row by row.

Reversible cutovers

Every migration ships with its inverse. If something looks wrong after the swap, one command puts it back.

Dry-runs in CI

Run the plan against a production snapshot on every pull request. If it would take a lock, the build fails.

A numbered audit trail

Each migration is a reviewable plan file with the exact DDL it will run, in order, forever.
