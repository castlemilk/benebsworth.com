  <header>
    <h1>Solve the system over the real numbers</h1>
    <div class="sub">x² + y² = 25&nbsp;&nbsp;and&nbsp;&nbsp;xy = 12</div>
  </header>

  <div class="system">
    x² + y² = 25<br>
    x · y = 12
  </div>

  <h2>Step 1 — Eliminate one variable by substitution</h2>
  <p>Since <em>xy</em> = 12, the product is nonzero, so neither variable is zero. Solve the second equation for <em>y</em>:</p>
  <div class="math">y = 12 / x        (x ≠ 0)</div>
  <p>Substitute into the first equation:</p>
  <div class="math">x² + (12 / x)² = 25
x² + 144 / x² = 25</div>

  <h2>Step 2 — Clear the denominator</h2>
  <p>Multiply through by x² (valid because x ≠ 0):</p>
  <div class="math">x⁴ + 144 = 25 x²
x⁴ − 25 x² + 144 = 0</div>

  <h2>Step 3 — Reduce with a substitution u = x²</h2>
  <p>This quartic is quadratic in x². Let u = x², so u ≥ 0:</p>
  <div class="math">u² − 25u + 144 = 0</div>
  <p>Apply the quadratic formula:</p>
  <div class="math">u = [25 ± √(25² − 4·1·144)] / (2·1)
     = [25 ± √(625 − 576)] / 2
     = [25 ± √49] / 2
     = [25 ± 7] / 2</div>
  <div class="math">u = 32/2 = 16      or      u = 18/2 = 9</div>
  <p>Both values are nonnegative, so both are admissible for u = x².</p>

  <h2>Step 4 — Recover x, then y</h2>
  <div class="math"><span class="c"># Case u = 16:</span>
x² = 16  →  x = 4   or  x = −4
y = 12 / x:
    x =  4  →  y = 3
    x = −4  →  y = −3

<span class="c"># Case u = 9:</span>
x² = 9   →  x = 3   or  x = −3
y = 12 / x:
    x =  3  →  y = 4
    x = −3  →  y = −4</div>

  <h2>Step 5 — Verify each pair</h2>
  <div class="check">
    (4, 3):  4² + 3² = 16 + 9 = 25 ✓&nbsp;&nbsp;|&nbsp;&nbsp;4·3 = 12 ✓<br>
    (−4, −3):  (−4)² + (−3)² = 16 + 9 = 25 ✓&nbsp;&nbsp;|&nbsp;&nbsp;(−4)(−3) = 12 ✓<br>
    (3, 4):  3² + 4² = 9 + 16 = 25 ✓&nbsp;&nbsp;|&nbsp;&nbsp;3·4 = 12 ✓<br>
    (−3, −4):  (−3)² + (−4)² = 9 + 16 = 25 ✓&nbsp;&nbsp;|&nbsp;&nbsp;(−3)(−4) = 12 ✓
  </div>

  <div class="answer">
    <div class="big">Solution set over ℝ:</div>
    <div class="sol">
      <span>(4, 3)</span>
      <span>(−4, −3)</span>
      <span>(3, 4)</span>
      <span>(−3, −4)</span>
    </div>
    <div class="note">All four pairs — exactly two in each quadrant along the diagonal.</div>
  </div>

  <h2>Cross-check — a cleaner route via (x ± y)²</h2>
  <div class="math">(x + y)² = x² + 2xy + y² = 25 + 24 = 49   →   x + y = ±7
(x − y)² = x² − 2xy + y² = 25 − 24 = 1    →   x − y = ±1</div>
  <p>Adding and subtracting the two sign combinations recovers the same four pairs
  (e.g. x + y = 7, x − y = 1 ⟹ x = 4, y = 3; x + y = −7, x − y = −1 ⟹ x = −4, y = −3; and the
  swapped-sign versions yield (3, 4) and (−3, −4)). This confirms the result and shows the
  geometry: the circle of radius 5 intersects the hyperbola xy = 12 in exactly four points,
  symmetric about the line y = x.</p>
