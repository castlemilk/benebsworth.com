<h1>Solve the system over the reals</h1>
<p class="math equation">x² + y² = 25, &nbsp; xy = 12.</p>
<div class="answer">
<strong>Every solution pair (x, y)</strong>
<span class="math">(4, 3), &nbsp; (3, 4), &nbsp; (−3, −4), &nbsp; (−4, −3).</span>
</div>
<h2>1. Find the sum and difference</h2>
<p>Expanding the square of the sum and substituting both given equations gives</p>
<p class="math equation">(x + y)² = x² + y² + 2xy = 25 + 2(12) = 49.</p>
<p>Thus <span class="math">x + y = 7</span> or <span class="math">x + y = −7</span>, since a real number whose square is 49 must be one of these two values.</p>
<p>Likewise, expanding the square of the difference gives</p>
<p class="math equation">(x − y)² = x² + y² − 2xy = 25 − 2(12) = 1.</p>
<p>Hence <span class="math">x − y = 1</span> or <span class="math">x − y = −1</span>. Both signs must be retained in each square-root step.</p>
<h2>2. Recover x and y for every sign choice</h2>
<p>Let <span class="math">s = x + y</span> and <span class="math">d = x − y</span>. Adding these equations yields <span class="math">s + d = 2x</span>; subtracting them yields <span class="math">s − d = 2y</span>. Dividing by the nonzero constant 2 therefore gives</p>
<p class="math equation">x = (s + d)/2, &nbsp; y = (s − d)/2.</p>

<h2>3. Verify the solutions and completeness</h2>
<p>For every row, <span class="math">s² = 49</span> and <span class="math">d² = 1</span>. Substituting the formulas for <span class="math">x</span> and <span class="math">y</span> into the original expressions gives</p>
<p class="math equation">x² + y² = [(s + d)² + (s − d)²]/4<br>= (s² + d²)/2 = (49 + 1)/2 = 25,</p>
<p class="math equation">xy = (s + d)(s − d)/4<br>= (s² − d²)/4 = (49 − 1)/4 = 12.</p>
<p>Thus all four pairs satisfy both original equations. Conversely, every real solution must have <span class="math">s ∈ {7, −7}</span> and <span class="math">d ∈ {1, −1}</span>, and each combination determines exactly one pair through the formulas above. The table exhausts these combinations, so there are no other real solutions.</p>
