<h1>Solving a Symmetric System over the Reals</h1>
<p class="sub">x² + y² = 25 &nbsp;and&nbsp; x·y = 12 &nbsp;— every real solution, with justification.</p>

<h2>1. The problem</h2>
<p>Find all <var>(x, y) ∈ ℝ²</var> satisfying</p>
<p class="system math">x² + y² = 25 &nbsp;&nbsp;①&nbsp;&nbsp;&nbsp;&nbsp; x·y = 12 &nbsp;&nbsp;②</p>
<p>Geometrically, ① is the circle of radius 5 centered at the origin, and ② is a rectangular
hyperbola lying in quadrants I and III (since <var>xy = 12 &gt; 0</var>, the two coordinates must have
the <em>same sign</em>). We expect intersection points symmetric about the origin.</p>

<h2>2. Solution via the sum–difference identities</h2>

<div class="step math">
  <h3>Step 1 — Compute (x + y)² and (x − y)²</h3>
  <p>The system is symmetric in <var>x</var> and <var>y</var>, so combine the equations into the two
  elementary symmetric combinations <var>s = x + y</var> and <var>d = x − y</var>. Using
  <var>(x + y)² = x² + y² + 2xy</var> and <var>(x − y)² = x² + y² − 2xy</var>:</p>
  <blockquote>
    (x + y)² = 25 + 2·12 = <strong>49</strong><br>
    (x − y)² = 25 − 2·12 = <strong>1</strong>
  </blockquote>
  <p class="why">Justification: these are identities — they hold for every real pair, so any
  solution of ①② must satisfy them. Adding/subtracting equations preserves the solution set
  (each step is reversible).</p>
</div>

<div class="step math">
  <h3>Step 2 — Take square roots</h3>
  <p>A real number <var>t</var> satisfies <var>t² = c</var> (for <var>c ≥ 0</var>) iff <var>t = ±√c</var>. Hence</p>
  <blockquote>
    x + y = ±7 &nbsp;&nbsp;&nbsp;&nbsp; x − y = ±1
  </blockquote>
  <p class="why">Both right-hand sides are positive, so real square roots exist. Each of the two
  signs is independent, giving at most 2 × 2 = 4 candidate pairs — this is also the <em>upper
  bound</em>: no other solutions can exist, because any solution must land in one of these four
  cases.</p>
</div>

<div class="step math">
  <h3>Step 3 — Solve each 2×2 linear system</h3>
  <p>For each sign choice, <var>x = (s + d)/2</var> and <var>y = (s − d)/2</var>:</p>
  <table>
    <tr><th>x + y</th><th>x − y</th><th>x = (s+d)/2</th><th>y = (s−d)/2</th><th>Solution</th></tr>
    <tr><td>+7</td><td>+1</td><td>4</td><td>3</td><td><strong>(4, 3)</strong></td></tr>
    <tr><td>+7</td><td>−1</td><td>3</td><td>4</td><td><strong>(3, 4)</strong></td></tr>
    <tr><td>−7</td><td>+1</td><td>−3</td><td>−4</td><td><strong>(−3, −4)</strong></td></tr>
    <tr><td>−7</td><td>−1</td><td>−4</td><td>−3</td><td><strong>(−4, −3)</strong></td></tr>
  </table>
  <p class="why">Justification: the linear map <var>(x, y) ↦ (x + y, x − y)</var> is a bijection of
  ℝ² (its matrix has determinant −2 ≠ 0), so solving the transformed system is equivalent to
  solving the original constraints on <var>(s, d)</var>. Each of the four cases yields exactly one
  pair.</p>
</div>

<div class="step math">
  <h3>Step 4 — Verify (sufficiency)</h3>
  <p>Steps 1–3 show every solution must be among the four candidates (necessity). To confirm each
  is actually a solution, substitute back:</p>
  <table>
    <tr><th>(x, y)</th><th>x² + y²</th><th>x·y</th><th>Both hold?</th></tr>
    <tr><td>(4, 3)</td><td>16 + 9 = 25</td><td>12</td><td class="check">✓</td></tr>
    <tr><td>(3, 4)</td><td>9 + 16 = 25</td><td>12</td><td class="check">✓</td></tr>
    <tr><td>(−3, −4)</td><td>9 + 16 = 25</td><td>12</td><td class="check">✓</td></tr>
    <tr><td>(−4, −3)</td><td>16 + 9 = 25</td><td>12</td><td class="check">✓</td></tr>
  </table>
  <p class="why">All four satisfy both equations, so the candidate list is the complete solution
  set — nothing missing (by necessity) and nothing extra (by sufficiency).</p>
</div>

<h2>3. Cross-check by substitution</h2>
<div class="step math">
  <p>Since <var>xy = 12 ≠ 0</var>, neither variable is zero, so ② legitimately gives
  <var>y = 12/x</var>. Substituting into ①:</p>
  <blockquote>
    x² + 144/x² = 25 &nbsp;⟹&nbsp; x⁴ − 25x² + 144 = 0
  </blockquote>
  <p>Let <var>u = x²</var> (valid since <var>x² ≥ 0</var>): <var>u² − 25u + 144 = 0</var>, with discriminant
  <var>Δ = 625 − 576 = 49</var>:</p>
  <blockquote>
    u = (25 ± 7)/2 = 16 &nbsp;or&nbsp; 9 &nbsp;⟹&nbsp; x = ±4 &nbsp;or&nbsp; x = ±3
  </blockquote>
  <p>Pairing each <var>x</var> with <var>y = 12/x</var> (which automatically forces the same sign) gives
  <var>(4,3), (−4,−3), (3,4), (−3,−4)</var> — exactly the same set. Note the sign pairing is not free:
  <var>(4, −3)</var> would give <var>xy = −12 ≠ 12</var>, which is why there are 4 solutions rather than 8.</p>
</div>

<h2>5. Answer</h2>
<div class="answer math">
  The system has exactly <strong>four</strong> real solutions:<br><br>
  <strong>(x, y) ∈ { (4, 3), (3, 4), (−3, −4), (−4, −3) }</strong>
</div>
<p class="why">Summary of the logic: the sum–difference identities transform ①② into
<var>(x+y)² = 49</var> and <var>(x−y)² = 1</var>, which bound the candidates to four linear cases
(necessity); each case produces one pair via <var>x = (s+d)/2, y = (s−d)/2</var>; direct
substitution confirms all four satisfy both original equations (sufficiency). The substitution
cross-check <var>x⁴ − 25x² + 144 = 0</var> factors as <var>(x²−9)(x²−16) = 0</var> and agrees.</p>
