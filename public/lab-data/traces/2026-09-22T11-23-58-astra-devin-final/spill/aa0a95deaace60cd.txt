<section aria-labelledby="contract-title"><h2 id="contract-title">Behavior and storage format</h2>
<ul>
<li><code>constant_time_compare(a, b)</code> compares text or bytes using <code>hmac.compare_digest</code>. Text is UTF-8 encoded, so matching text and bytes compare equal.</li>
<li><code>hash_password(password, iterations=600_000)</code> generates a fresh salt with <code>secrets.token_bytes(16)</code> and returns the record below. Iterations are keyword-only and must be an integer between 600,000 and 2,000,000.</li>
<li><code>verify_password(password, stored_hash)</code> uses the stored salt and work factor, then compares the 32-byte keys. Wrong passwords and malformed records return <code>False</code>. Invalid password types raise <code>TypeError</code>.</li>
<li>Unicode is preserved without normalization. Empty passwords and embedded NUL bytes are supported. Text with unpaired surrogates raises <code>UnicodeEncodeError</code>.</li>
</ul>
<pre><code>pbkdf2_sha256$iterations$salt_hex$key_hex
                         32 hex   64 hex</code></pre>
<p class="note">This is a module-specific, strictly parsed format. Records outside the supported work-factor range are rejected before PBKDF2 runs. The upper bound limits the cost of a single record; it is an implementation policy, not a PBKDF2 limit.</p>
<p class="note"><strong>Timing scope:</strong> the comparison avoids content-dependent early exits. Input lengths, UTF-8 encoding, malformed-record rejection, and different work factors can affect overall timing. The complete verification flow is not constant-time. <a href="https://docs.python.org/3/library/hmac.html#hmac.compare_digest">Python documents the comparison's timing guarantees.</a></p></section>

import hashlib
import hmac
import re
import secrets

__all__ = [&quot;constant_time_compare&quot;, &quot;hash_password&quot;, &quot;verify_password&quot;]

DEFAULT_ITERATIONS = 600_000
MIN_ITERATIONS = 600_000
MAX_ITERATIONS = 2_000_000
SALT_BYTES = 16
KEY_BYTES = 32
_RECORD = re.compile(
    r&quot;pbkdf2_sha256\$([1-9][0-9]{0,6})\$([0-9a-f]{32})\$([0-9a-f]{64})&quot;
)


def _to_bytes(value: str | bytes) -&gt; bytes:
    if isinstance(value, str):
        return value.encode(&quot;utf-8&quot;)
    if isinstance(value, bytes):
        return value
    raise TypeError(&quot;expected str or bytes&quot;)


def constant_time_compare(left: str | bytes, right: str | bytes) -&gt; bool:
    &quot;&quot;&quot;Compare text or bytes without content-based early exits.

    Mixed str/bytes inputs compare their byte representations. Unsupported
    types raise TypeError; unpaired surrogates raise UnicodeEncodeError.
    Lengths and UTF-8 encoding time are not hidden by this function.
    &quot;&quot;&quot;
    return hmac.compare_digest(_to_bytes(left), _to_bytes(right))


def hash_password(
    password: ***REDACTED*** | bytes, *, iterations: int = DEFAULT_ITERATIONS
) -&gt; str:
    &quot;&quot;&quot;Return a salted PBKDF2-HMAC-SHA256 record suitable for storage.

    iterations must be an integer (not bool) between 600,000 and 2,000,000.
    Tune within this range for your hardware; review the policy over time.
    Invalid types raise TypeError; out-of-range work factors raise ValueError.
    &quot;&quot;&quot;
    password_bytes = _to_bytes(password)
    if type(iterations) is not int:
        raise TypeError(&quot;iterations must be an integer&quot;)
    if not MIN_ITERATIONS &lt;= iterations &lt;= MAX_ITERATIONS:
        raise ValueError(
            f&quot;iterations must be between {MIN_ITERATIONS} and {MAX_ITERATIONS}&quot;
        )
    salt = secrets.token_bytes(SALT_BYTES)
    key = hashlib.pbkdf2_hmac(
        &quot;sha256&quot;, password_bytes, salt, iterations, dklen=KEY_BYTES
    )
    return f&quot;pbkdf2_sha256${iterations}${salt.hex()}${key.hex()}&quot;


def verify_password(password: ***REDACTED*** | bytes, stored_hash: str) -&gt; bool:
    &quot;&quot;&quot;Check a password against a record created by hash_password.

    Wrong passwords and malformed/unsupported records return False, including
    non-str records. Invalid password types raise TypeError. Unicode text
    must be UTF-8 encodable. Record checks precede expensive derivation.
    The final comparison compares two 32-byte keys with compare_digest.
    &quot;&quot;&quot;
    password_bytes = _to_bytes(password)
    if not isinstance(stored_hash, str) or len(stored_hash) &gt; 128:
        return False
    match = _RECORD.fullmatch(stored_hash)
    if match is None:
        return False
    iterations_text, salt_hex, key_hex = match.groups()
    iterations = int(iterations_text)
    if not MIN_ITERATIONS &lt;= iterations &lt;= MAX_ITERATIONS:
        return False
    salt = bytes.fromhex(salt_hex)
    expected = bytes.fromhex(key_hex)
    actual = hashlib.pbkdf2_hmac(
        &quot;sha256&quot;, password_bytes, salt, iterations, dklen=KEY_BYTES
    )
    return constant_time_compare(actual, expected)

        self.assertNotEqual(self.record, second)
