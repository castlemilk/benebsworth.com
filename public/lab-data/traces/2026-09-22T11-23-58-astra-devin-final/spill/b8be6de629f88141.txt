Usage:
    stored = hash_password(&quot;a long, unique passphrase&quot;)
    assert verify_password(&quot;a long, unique passphrase&quot;, stored)

Store the entire returned record; the salt is public. Run the bundled tests:
    python3 password_hashing.py -v

UTF-8 is used without normalization or trimming. Empty passwords are supported;
password-strength policy belongs to the application. Passwords are limited to
1024 encoded bytes. The default and minimum work factor is 600,000 iterations;
the 2,000,000 upper limit bounds work when parsing stored records.

Only the final digest comparison avoids content-dependent short circuiting.
Encoding, lengths, record parsing, and the whole login flow are not guaranteed
constant-time. No timing benchmark can establish that guarantee in a unit test.
&quot;&quot;&quot;</span>

<span class="keyword">import</span> hmac
<span class="keyword">import</span> re

DEFAULT_ITERATIONS = <span class="number">600_000</span>
MIN_ITERATIONS = <span class="number">600_000</span>
MAX_ITERATIONS = <span class="number">2_000_000</span>
SALT_BYTES = <span class="number">16</span>
KEY_BYTES = <span class="number">32</span>
MAX_PASSWORD_BYTES = <span class="number">1024</span>
_RECORD = re.compile(
    <span class="string">r&quot;pbkdf2_sha256\$([1-9][0-9]{0,6})\$([0-9a-f]{32})\$([0-9a-f]{64})&quot;</span>

<span class="keyword">def</span> constant_time_compare(left: str, right: str) -&gt; bool:
    <span class="string">&quot;&quot;&quot;Compare UTF-8 strings using hmac.compare_digest.

    No early exit based on matching content; lengths can still affect timing.
    Non-string inputs raise TypeError; invalid Unicode raises UnicodeEncodeError.
    &quot;&quot;&quot;</span>
    <span class="keyword">if</span> <span class="keyword">not</span> isinstance(left, str) <span class="keyword">or</span> <span class="keyword">not</span> isinstance(right, str):
        <span class="keyword">raise</span> TypeError(<span class="string">&quot;both values must be strings&quot;</span>)
    <span class="keyword">return</span> hmac.compare_digest(left.encode(<span class="string">&quot;utf-8&quot;</span>), right.encode(<span class="string">&quot;utf-8&quot;</span>))


<span class="keyword">def</span> _password_bytes(password: ***REDACTED*** -&gt; bytes:
    <span class="keyword">if</span> <span class="keyword">not</span> isinstance(password, str):
        <span class="keyword">raise</span> TypeError(<span class="string">&quot;password must be a string&quot;</span>)
    <span class="comment"># Check character count first to avoid encoding an unbounded input.</span>
    <span class="keyword">if</span> len(password) &gt; MAX_PASSWORD_BYTES:
        <span class="keyword">raise</span> ValueError(<span class="string">&quot;password exceeds 1024 UTF-8 bytes&quot;</span>)
    encoded = password.encode(<span class="string">&quot;utf-8&quot;</span>)
    <span class="keyword">if</span> len(encoded) &gt; MAX_PASSWORD_BYTES:
        <span class="keyword">raise</span> ValueError(<span class="string">&quot;password exceeds 1024 UTF-8 bytes&quot;</span>)
    <span class="keyword">return</span> encoded


<span class="keyword">def</span> hash_password(password: ***REDACTED***, *, iterations: int = DEFAULT_ITERATIONS) -&gt; str:
    <span class="string">&quot;&quot;&quot;Create a fresh random salt and return algorithm$iterations$salt$hash.

    Salt and hash are lowercase hex. Invalid types raise TypeError; out-of-range
    iterations or passwords raise ValueError. Lone Unicode surrogates are invalid.
    &quot;&quot;&quot;</span>
    raw = _password_bytes(password)
    <span class="keyword">if</span> type(iterations) <span class="keyword">is</span> <span class="keyword">not</span> int:  <span class="comment"># bool must not count as an integer here.</span>
        <span class="keyword">raise</span> TypeError(<span class="string">&quot;iterations must be an integer&quot;</span>)
    <span class="keyword">if</span> <span class="keyword">not</span> MIN_ITERATIONS &lt;= iterations &lt;= MAX_ITERATIONS:
        <span class="keyword">raise</span> ValueError(<span class="string">&quot;iterations must be between 600000 and 2000000&quot;</span>)
    salt = secrets.token_bytes(SALT_BYTES)
    digest = hashlib.pbkdf2_hmac(<span class="string">&quot;sha256&quot;</span>, raw, salt, iterations, dklen=KEY_BYTES)
    <span class="keyword">return</span> f&quot;pbkdf2_sha256${iterations}${salt.hex()}${digest.hex()}&quot;


<span class="keyword">def</span> verify_password(password: ***REDACTED***, stored: str) -&gt; bool:
    <span class="string">&quot;&quot;&quot;Verify against a stored record using its salt and iteration count.

    Return False for a mismatch, invalid input, or malformed/unsupported record.
    Unexpected runtime failures propagate. Record validation happens before the
    expensive derivation; malformed records are not processed in constant time.
    &quot;&quot;&quot;</span>
    <span class="keyword">if</span> <span class="keyword">not</span> isinstance(stored, str) <span class="keyword">or</span> len(stored) &gt; <span class="number">128</span>:
        <span class="keyword">return</span> <span class="keyword">False</span>
    match = _RECORD.fullmatch(stored)
    <span class="keyword">if</span> match <span class="keyword">is</span> <span class="keyword">None</span>:
        <span class="keyword">return</span> <span class="keyword">False</span>
    rounds, salt_hex, digest_hex = match.groups()
    iterations = int(rounds)
    <span class="keyword">if</span> <span class="keyword">not</span> MIN_ITERATIONS &lt;= iterations &lt;= MAX_ITERATIONS:
        <span class="keyword">return</span> <span class="keyword">False</span>
    <span class="keyword">try</span>:
        raw = _password_bytes(password)
    <span class="keyword">except</span> (TypeError, ValueError):
        <span class="keyword">return</span> <span class="keyword">False</span>
    actual = hashlib.pbkdf2_hmac(
        <span class="string">&quot;sha256&quot;</span>, raw, bytes.fromhex(salt_hex), iterations, dklen=KEY_BYTES
    )
    <span class="keyword">return</span> hmac.compare_digest(actual, bytes.fromhex(digest_hex))

<section class="details-grid" id="notes" aria-label="Implementation notes">
<div><h3>A record that carries its parameters</h3><code class="record">pbkdf2_sha256$600000$&lt;32 hex salt chars&gt;$&lt;64 hex hash chars&gt;</code><p>The salt comes from <code>secrets.token_bytes(16)</code> and is stored with the digest. Verification reads that salt and iteration count; it never generates a replacement salt. This is the module’s own format.</p><p>The 600,000-round default follows the <a href="https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#pbkdf2">OWASP PBKDF2-HMAC-SHA256 work factor</a>. This module accepts 600,000–2,000,000 rounds; the upper bound is a local resource limit. Benchmark on your deployment hardware before tuning it.</p></div>
<div><h3>Precise input and timing behavior</h3><p>Strings are encoded as UTF-8 without normalization or trimming. Empty passwords are supported; strength rules belong to your application. Hashing rejects invalid inputs and passwords over 1,024 encoded bytes. Verification returns <code>False</code> for invalid inputs and unsupported records.</p><p><a href="https://docs.python.org/3/library/hmac.html#hmac.compare_digest">Python’s comparison primitive</a> avoids content-based short circuiting. Length, encoding, parsing, and invalid-input paths can still affect runtime. The complete verification or login flow is not guaranteed to take constant time.</p><p>Derivation uses <a href="https://docs.python.org/3/library/hashlib.html#hashlib.pbkdf2_hmac">hashlib.pbkdf2_hmac</a> with a fixed 32-byte output. No third-party Python packages are required.</p></div>
