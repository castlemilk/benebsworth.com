# Motion study design brief

Preserved written implementation prompt; **no image-generation call was made**. This is design intention, not a screenshot or scientific evidence.

Continue Ben Ebsworth's open-margin research folio. Use the existing local Source Serif 4 for reading, Barlow Condensed for concise labels and selectable Caveat for one useful red observation. Keep the reading argument and source identity still. Show four exact source-backed fixtures from two published article–lab pairs, retaining their registry keys and evidence. Give the fixed reading root, inspected item and keyboard focus distinct text and structural cues.

Use open whitespace, quiet rules and a readable inline inspector. Selection changes content immediately; only a small decorative ink mark may settle over 120–180 ms. The inspector's words never fade or slide. Filtering uses immediate results and a concise status. The existing circuit mark may receive one explicit arrival review; preserve its original bytes and keep its label readable. It is a metaphor, not a simulated circuit.

Keep native links and GET forms useful before JavaScript. Reserve sufficient space for context, retain excluded inspected/focused items honestly, and avoid layout changes during pointer activation. Use an explicit details anchor on narrow layouts. Let browser Back restore reading position. Respect live reduced-motion and forced-colour preferences; interruption or teardown leaves the fully visible final state.

Do not design a second graph model, production inspector, guide-onboarding state machine, global token system or UI SDK migration. Do not introduce orbital decoration, false physical movement, autoplay audio, forced focus/scroll or tracking. Keep About and Hiking separate. Preserve exact source titles, paths and provenance.

## Decisions

- **Adopt in specimen:** native source list and inline inspection region, local folio typography, selectable red note, structural focus/inspection differences, finite empty-decoration effects, explicit error/empty states.
- **Offer as reusable candidate:** `motion.mjs` and its lifecycle contract.
- **Leave to owners:** production graph rendering and URL schema; source equivalence; modal inspector; global tokens; first-entry guide policy; category artwork choices.
- **Review pending:** actual typographic hierarchy, margins, wrapping, forced-colour appearance, 320/390/1280 px layout and keyboard/pointer sequences. No generated image stands in for those observations.
